## What data is collected and why

### Hosting (GitHub Pages)
This site is hosted on GitHub Pages. When you open a page, GitHub logs and stores your IP address for security purposes, as any web server does. I have no access to these logs. See [About GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) and [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

### Analytics (GoatCounter)
This site uses [GoatCounter](https://www.goatcounter.com/) for privacy-friendly analytics. The counting script is loaded from GoatCounter's servers. GoatCounter collects anonymised, aggregated data including:
- Pages visited
- Country/region of origin
- Device and browser type
- Referral source (how you found the site)

GoatCounter does **not** use cookies and does not collect any personally identifiable information. No tracking across sites. No data is sold or shared.

### Comments (Giscus)
This site uses [Giscus](https://giscus.app) for comments, powered by GitHub Discussions. The comment section is loaded from giscus.app when you scroll down to it on a post, so your browser contacts Giscus at that point even if you do not comment. If you leave a comment, your GitHub username and comment content are stored in the GitHub repository for this blog. This is subject to the [Giscus Privacy Policy](https://github.com/giscus/giscus/blob/main/PRIVACY-POLICY.md) and [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

### Contact form (Formspree)
The contact form is processed by [Formspree](https://formspree.io/). When you press Send, your name, email address, subject and message are transmitted to Formspree, which forwards them to me by email. Nothing is transmitted before you send the form. I use these messages only to answer your request. See [Formspree's Privacy Policy](https://formspree.io/legal/privacy-policy/).

### Fonts, icons and scripts
Fonts, icons and JavaScript libraries are served from this site itself. Reading a page does not contact Google Fonts or any other content delivery network.

### No cookies
This site does not set any first-party cookies. GoatCounter is cookieless by design. Giscus may set cookies only if you interact with the comment section.

## Legal basis (GDPR)

The legal basis for processing analytics data is **legitimate interest** (Article 6(1)(f) GDPR) - understanding how content is used helps improve it. No data is sold or shared with third parties beyond the services listed above.
